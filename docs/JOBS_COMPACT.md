# 任务中心：紧凑折叠与增量渲染

## 改了什么

一张卡从 ~120px 压到 **33px**，一行看完标题、工具、时间、状态；点开才展开会话与输出预览。

```
┌────────────────────────────────────────────────────────────┐
│ ● 写滚动回归文档        file_write  21:12  已完成        ⌄ │  33px
├────────────────────────────────────────────────────────────┤
│ file_write  会话 无项目                                    │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ File written: docs/VIEW_SCROLL_MEMORY.md  Size: 2620 B │ │  101px（展开）
│ └────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

实测（真实 Chromium，6 条夹具）：`[101, 33, 33, 33, 33, 33]`。
折叠态比原来省了约 **72%** 的纵向空间，一屏能看 20 条以上。

## 为什么之前一直重绘

`applyJobUpdate()` 每收到一个 `job` 事件就把整张列表 `innerHTML` 重建一次。而一个回合里
每个工具调用会发 **4 个** job 事件：

| 事件 | 服务端位置 |
|---|---|
| `tool_complete` → 新建任务 | `createToolJob` + `emitTurnEvent('job', job)` |
| `onToolExecutionStart` → running | 同上 |
| `onToolState` → 状态迁移 | 同上 |
| `onToolResult` → 完成 / 失败 | 同上 |

十个工具调用 = 40 次全量重建，每次都要重新解析 N 张卡的 HTML——而这段时间聊天区正在
流式渲染 token，两者抢同一个主线程。更糟的是，**即使当时停在对话页、任务中心根本不可见**，
重建照样发生（视图是保活的，DOM 一直在文档里）。

## 现在的三条闸门

1. **视图不可见就不碰 DOM**：`renderJobs()` 先看 `#view-jobs` 是否 `.active`。不可见时只更新
   左侧导航的运行中计数（便宜且用户看得见），列表留给切回时用缓存绘制。
2. **按卡比对**：每张卡记一个 `shape` 指纹（状态 / 标题 / 工具 / 时间 / 输出 / 会话名）。
   指纹相同直接 return，一个 DOM 写都不做。
3. **按 id 复用节点**：`jobCardNodes: Map<id, entry>`，卡片元素只创建一次，之后只改变化的
   那几个文本节点；顺序用一次 `insertBefore` 修复，删掉的 id 再移除。

实测：**连续三次相同数据的轮询，`MutationObserver` 计数为 0**。轮询间隔仍是 2.5s，但现在
一次空轮询不产生任何布局或重绘。

此外，窗口最小化（`document.hidden`）时轮询直接停掉，恢复时再拉一次。

## 折叠状态

`jobsExpanded: Set<jobId>`，点击委托在 `#jobsList` 上挂一次，卡片不做重建后丢事件。
节点复用意味着展开状态天然保留——以前的那种「重建后卡片全部收起」不会发生。
`aria-expanded` / `aria-controls` / `hidden` 让读写和键盘（Enter / Space）都按原生按钮走。

## 顺带修掉

`刷新` 按钮过去会被 flex 行拉满（用户截图里那个横跨半屏的胶囊）。现在
`.jobs-container .settings-header .btn-sm { flex: 0 0 auto; }`，实测宽 **60px**，
标题与按钮间距 > 0。

## 验证

`tests/browser-jobs-compact.test.js`（真实 Chromium，12 条夹具）：

- 折叠卡高 ≤ 44px，`aria-expanded=false`，详情 `hidden`
- 点击展开：详情可见、输出文本正确、卡片变高
- 更新同一条任务：**同一个 DOM 节点**被复用，状态文本变化，且仍然保持展开
- 相同数据连打 3 次：**0 次 DOM 变更**
- 切到对话页后投递新任务：列表 0 变更，徽标仍然更新；切回时用缓存绘制，新任务在最前
- 刷新按钮宽 ≤ 120px 且与标题不重叠

全量 **661 / 661**。
