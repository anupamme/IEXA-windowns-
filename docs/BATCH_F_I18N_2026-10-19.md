# 批次 F：界面国际化（2026-10-19）

## 方案

`app.js` 约 8500 行、中文文案散布在静态 HTML 与动态模板中。一次性全量替换风险过高，
因此采用**框架先行 + 核心界面覆盖**的增量方案：

| 层 | 做法 |
|---|---|
| 静态文案 | 元素加 `data-i18n` / `data-i18n-placeholder` / `data-i18n-title` / `data-i18n-aria`，启动时替换 |
| 动态文案 | 调用 `IexaI18n.t(key, params)` |
| 缺失键 | 回退到中文；再缺失则返回 key 本身（便于发现漏翻） |
| 语言持久化 | `localStorage['iexa-locale']`，同步到 `<html lang/data-locale>` |
| 首次启动 | 读本地存储 → `navigator.language` → 默认 `zh-CN` |

## 文件

- 新增 `src/renderer/services/I18n.js`（中英字典 + `t` / `setLocale` / `apply` / `onLocaleChange`）
- `index.html`：引入脚本、导航与核心控件标注、设置页新增「界面语言」下拉
- `app.js`：命令面板、斜杠命令、检查点面板、诊断导出、权限标签、工具名改用 `t()`

## 已覆盖范围

- 左侧导航全部条目、项目分组、打开项目
- 会话搜索框
- 命令面板（13 个动作 + 占位符 + 空状态）
- 斜杠命令（6 条 + `/help` 输出）
- 检查点面板（标题、刷新、加载/空/错误、文件数、回退按钮与确认文案）
- 诊断区块（标题、说明、导出中/成功/失败）
- 权限模式四档标签
- 15 个工具的中文显示名

## 未覆盖（后续增量）

`app.js` 中大量细粒度提示（错误信息、设置项说明、插件/MCP 面板文案）仍为中文。
这些文案会在 en 界面下回退显示中文，不影响功能。后续可按视图逐步迁移：
`settings` → `skills` → `mcp` → `plugins` → `sync`，每批替换后跑一次全量。

## 验证

| 项 | 结果 |
|---|---|
| `tests/i18n.test.js` | **6/6**（默认语言、切换、插值、归一化、双字典键对齐、占位符一致性） |
| 真实浏览器 | 默认 `zh-CN` → 切 en 后导航 `Chat/Skills`、搜索框 `Search sessions`、权限标签英文、命令面板 `New task`（13 项）→ 刷新保持英文 → 切回中文恢复 |
| 全量 | 见提交说明 |
